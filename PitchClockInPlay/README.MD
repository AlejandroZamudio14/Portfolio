# **Pitch Clock in Play - Academic Project**
Analysis of Pitcher Performance Following the 2023 Pitch Clock implmentation

**Course:** SDS 336 - Practical Machine Learning

**Tools:** Python, Pandas, Scikit-lean, Seaborn

**Semester:** Fall 2024

Description: In 2023, Major league Baseball introduced the Pitch Clock, a timer indicating when a pitcher must begin their motion of throwing a pitch. With the league aiming to speed up the pace of the game, it was possible that notable changes in performance could be observed amongst pitchers. In this project, our group was interested to see that if we could identify any difference in pitcher performance from the 2021 and 2022 season to the 2023 season. Our group looks at both, play by play and aggregate data in order to try to identify common trends any any notable difference. Our group also attempts to create machine learning models to help us identify notably different performances. The intent was to train on aspects of performance and see if player performance in the 2023 season was different from proposed performance prior to the pitch clock. The Repository contains Python code from the shared colab file as well as a PDF containing our groups final report. The final report follows the instructions and feedback provides from the assignment the project was part of

Note: This project was completed in Fall 2024 as part of a group project. Original datasets used in analysis are no longer accessible and project code is altered to remove unnecessary steps not relevant to analysis.
