# **The Game Away from Home - Academic Project**
Analysis of the Texas Longhorns Softball Team's performance at home and on the road

**Course:** SDS 375 - Sports Analytics
**Tools:** R, tidyverse, ggplot2
**Semester:** Spring 2025

Description: With the changing environment in College Sports, many teams find themselves travelling longer distances in order to play competitions. While research has gone into the affects of travel on collegiate athletes, our group was interested in finding notable differences in performance, specifically in Softball. Using the SoftballR package and using Recap Summaries on the team's website, our group focuses on the 2022 to 2024 season for the Texas Longhorns Softball Team. Our group looks at both Hitting and Pitching performance in order to analyze trends throughout the three seasons and see if performance tend to be better at home or on the road. The repository contains CSV files containing the data used for the analysis, the R script file that analysis was performed on, and the final report submitted for the assignment.
